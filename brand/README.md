# OpenDive Atlas logo files

Vector artwork for print and digital use. All text is converted to outlines, so no fonts are needed.

| File | Use |
| --- | --- |
| `opendive-atlas-mark.svg` / `.pdf` | The mark on its own: a school of fish forming a map pin around a squirrelfish. Social avatars, stickers, merchandise, small spaces. |
| `opendive-atlas-logo-on-dark.svg` / `.pdf` | Mark and name exactly as in the website header: cream and fin-blue text, transparent background. For dark backgrounds. |
| `opendive-atlas-logo-on-dark-with-background.svg` / `.pdf` | The same on a navy panel, ready to place on any background. |
| `opendive-atlas-logo-on-light.svg` / `.pdf` | Navy and deep-blue text for white or light paper. |

SVG suits web, signage and most design tools (Illustrator, Affinity, Inkscape, Canva). PDF is the usual choice for printers. Each PDF is a single vector page, 80 mm wide; scale freely.

## Using the logo

- **Clear space:** keep empty space around the logo at least the width of the squirrelfish on every side.
- **Minimum size:** the full logo 30 mm wide in print (about 120 px on screen); the mark alone 8 mm tall.
- **Don't** stretch, recolour, rotate, add effects, or put the light version on dark backgrounds (or the other way round).
- **Typeface:** the name is set in Poppins (Medium for OPENDIVE, Regular for ATLAS), free from Google Fonts.

These files were generated from the site's own logo component (`src/components/layout/logo-mark.tsx` and `logo.tsx`), so they match the website exactly.
